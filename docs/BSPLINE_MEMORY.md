# 当前六帧空间记忆 B-spline 链路

当前修复版本为 `bspline_unified_spatial_omni_v4`，actor 语义为
`native16_euler2_unified_spatial_independent_free_v9`。旧 v3 检查点只能在其保存的源码下评测；不能自动迁移到本版本。

## 观测、记忆与执行

每次规划使用当前帧及过去六秒的五个时间段各抽一帧。空段无效，不复制帧。
每次写入保存实际帧 ID、标定、位姿、时间和 cell 来源。训练用当前参数重算来源图像特征，
不把旧模型的 learned feature 当输入。在线与重放共用 `fuse_sources`、`encode_memory`。

唯一空间记忆的共享空间特征直接产生几何场和 256 个环境 token，再结合五个历史运动 token。
G/Q 共用这一条件。没有独立视觉 reader 或几何场二次 token 编码分支。
读取范围为当前位姿周围 ±12m，8192 个读取 cell 的上限超过时明确报错，不静默裁剪。

固定 8 控制点、三次 B-spline、14 维标准化控制点增量、16 候选和两步 Euler。
执行器沿 Q argmax 的原始候选平移，每 0.5 秒走最多 0.25m 弧长，保持 yaw。
没有候选修复、安全筛选、回退控制器或 MPC 速度折扣。

## 专家、数据与标签

专家从源地图规划、投影到同一原生 B-spline 表示，再进行真实执行与资格检查。
必须同时满足实测障碍点净距、源地图净距、物理箱体净距和连续采样余量。
拟合失败或不合格轨迹不能以空标签、放宽阈值或备用路线进入数据。

采集器按实际移动 0.2m、转向或原任务阶段变化记录状态，保留全部已采状态。
每条独立轨迹显式指定 `train` 或 `validation`；整条轨迹归属同一分区，
不再按状态序号切分、强制把终点留验或按任务最多抽取 12 条。
轨迹完整性由原任务成功条件和执行预算定义，不要求短任务凑满样本数或额外路程。
前缀知识从本次实际深度重新审核；每条专家在采集时直接通过训练 Q 使用的同一失败判据。
任务差异集中在既有目标、完成条件和失败定义中，共用观测、几何资格和数据写入过程。

CPU 原始采集标记为 `cpu_collection_pending_native_replay_v1`，不能直接进入训练。
CPU 阶段保存原始观测、写入选择和专家标签，不额外保存可重建的记忆计划。
`prepare_six_frame_replay` 在 CUDA 上按记录的写入选择重建记忆输入后，才标记
`cuda_native_projection_v1`。传感器数据、专家和几何标签保持原样。
现有验证文件固定不动；新增独立轨迹只加入其声明的数据分区。

几何标签合同为 `observed_hit_clearance_raw_spatial_gradient_v2`：

- 净距 d*(x) = 最近实际观测 hit 的距离 − 测量误差 − 机器人半径。
- 自由证据 f*(x) 由真实历史深度的完整 footprint 观测产生；未知区域为 0。
- 正净距不等于已观测自由。
- 数据、GF 与教师资格使用同一 hit 索引、误差和半径。源地图仅供离线教师使用。

D2 原评测在合法退出后仍执行至原预算，因此采集也必须覆盖完整预算。
退出后继续从真实观测前沿选择目标，源 C-space 决定可达性，最终路径仍通过原资格检查。
已经到达的前沿接近点不再作为新平移目标。失败的完整历史不准入。

D2 的已确认分支证据保存在 raw 中并绑定原始审计文件 SHA。
每条状态的 fork_seen 只从当前采集截止前的实际执行历史产生，不读取后续帧。
数据加载时，专家还必须通过 Q 使用的同一物理/任务失败判据。
K/L/J 保留原任务终止定义；训练与验证仍是同 40 个场景内不同状态，不是独立场景泛化验证。

## 各损失与梯度

记 H=3.6m，Δ=2H/63；z 为高斯噪声，a* 为专家的标准化控制点增量。
总损失仍为 CFM + TRAJ + GF + LH + LQ，没有为改善数字额外调权重。

### CFM 与两步积分

x_t=(1−t)a*+tz，v*=z−a*，t∈{1,1/2}。
CFM 是速度残差平方在时间、14 维坐标及状态上的均值。

x_1=z−0.5vθ(z,1,c)
a_hat=x_1−0.5vθ(x_1,1/2,c)

两次 G 调用及其中的路径几何读取均保留梯度。非重入 checkpoint 只重算激活，不 detach。
对任意 G 参数 θ：

∂a_hat/∂θ=−0.5[(I−0.5∂v₂/∂x₁)∂v₁/∂θ+∂v₂/∂θ]。

解析场 v(x,t,c)=(x−a*)/t 在这条 bridge 上同时实现 CFM=0 和两步最终轨迹=专家。
已对当前3213条真实标签核对：控制点归一化往返最大误差2.39e−7m，FP64解析两步恢复的坐标残差为0。
这是给定专家的解析 oracle，用于核对公式、积分符号和坐标变换，不作为网络输入。
它不证明真实观测足以唯一确定专家，也不证明有限网络已经学到该解。

### TRAJ

全部 16 条最终曲线分别匹配同条件的合格专家，不只选择一条好候选。
损失是位置误差除以 H 后的均方，加上参数方向一阶差分（乘以 63）误差除以 H 后的均方。
多专家只能共享相同因果历史、memory plan、位姿和可见任务目标。

这个无量纲标量不是米制 RMSE，也不是成功率。必须另看米制位置误差与实际执行前缀。

### GF

对 257 个实际曲线采样点，令 m=dist(hit)−error−radius，
ε=sup|C'(u)|/[2(N−1)]，δ=max((ε−m)/radius,0)。
风险为 4·max_u h(δ)，其中 h(δ)=δ²（δ≤1），否则 2δ−1；再平均候选与状态。

最近 hit 的索引离散选择不求导，距离对曲线坐标的梯度保留；采样余量同样参与梯度。
满足余量时 GF=0、梯度=0 是正确结果。原760条与新增2453条专家均通过该检查。
局部 TRAJ/GF 梯度可以相反；这与“专家本身被 GF 惩罚”不是同一问题。

### LH

净距输出 d=H·logit_d，自由输出 f=sigmoid(logit_f)，两个监督不互相门控。
占据特征 o=sigmoid(−d/Δ)，support=o+(1−o)f，只作派生特征。

LH = Huber((d−d*)/Δ) + 相邻净距差分匹配 + BCEWithLogits(logit_f,f*)。

因此自由 BCE 对独立净距输出的偏导为 0；对 logit_f 的偏导为 sigmoid(logit_f)−f*（再按均值缩放）。
删除的旧定义 f=sigmoid(logit_f)·sigmoid(d/Δ) 会迫使自由 BCE 改变已正确的距离：
例如真实净距 1cm 时 f≤0.522，却要求匹配标签 1，形成不可消除的头部监督冲突。
共享 CNN 仍会收到两项学习信号；并不人为切断共享表征梯度。

### Q

候选路径、专家及记录路径均 detach 后计算教师效用；Q 不直接更新 G。
Q 及共享条件表征接收回归梯度。标签使用真值几何/观测标签，不使用预测几何自举。

失败 = 物理碰撞，或原 fixed40 的确认分支重入规则被违反。
K 的已确认闭合分支、L/D2 达到岔口后的已确认分支重入为任务失败。
从已知腿内部向外返回是合法的。J 的有目标导航不应用这些无目标分支限制。
物理/任务失败后的区域不能产生进展或探索收益。

令 e 为首次失败前最后一个有效点，L 为完整曲线长度。
有目标 P=d_source(start,goal)−d_source(e,goal)。
无目标 P=d_source(start,e)·(1+n)，n 只统计同一有效前缀的历史观测未知比例；
超出观测标签范围的部分不凭空产生 novelty。

U=(P−0.5L)/H−failure−asinh(relu(extra_margin−minimum_clearance)/radius)。

Q 用 smooth-L1 回归 U；有专家时权重为专家 0.25、当前候选 0.375、记录候选 0.375。
没有新增任务惩罚系数；已有失败项覆盖评测本就定义的失败。
Q 是有限窗口的效用近似，并不构成对长期探索成功率或绝对安全的证明。

## 优化、验收与当前状态

所有学习模块共同接受一次 AdamW 更新和 EMA。CNN 在本次修复验收期间保持可训练。
不通过梯度裁剪、loss 重加权、隐藏目标、推理安全筛选或放宽教师检查掩盖问题。

检查包括：旧实现失败/修复后通过的回归用例、真实专家共同可行性、真实状态分项梯度、
完整 D2 数据准入、保存/恢复及最终完整 40 案。短跑不代替完整训练或导航评测。

## 当前数据、采样与监控

使用唯一 `data/curvenav_expert/dataset_summary.json`，3019 条训练状态、原194条验证状态。40任务逐任务等权，任务内循环所有历史与状态：K/L/D2各20%，J40%。不按轨迹长度或状态总量增加任务权重。

完整覆盖 epoch 的步数为 `ceil(最大任务状态数 × 任务数 / 全局batch)`。当前最大482、任务40、全局176，得到110步/epoch；50epoch为5500步。严格恢复同一运行仍要求源代码、数据与预算合同一致；更换数据需显式 `--new-data-stage`，保留 AdamW/EMA/RNG，从新数据 epoch0计步，保留当前LR并按新预算继续余弦衰减，不重复预热。

主比较指标来自每个checkpoint的完整训练集和验证集：同一份EMA，每任务内取状态均值，再对全部任务取均值。固定评估噪声且不推进训练RNG；同次比较的CNN特征只计算一次并在两个分区间复用，换权重后重算。`validation_history`中的`train`是对应训练指标，顶层CFM/TRAJ/GF/LH/LQ是对应验证指标。逐优化步`trace`明确标记raw权重、优化前batch均值，不与主比较指标混淆。

验证文件、标签和原40案的成功阈值不变；模型、loss系数与执行约束不变。补采后的完整训练与40案结果必须由新数据阶段实际运行产生。
